# Features

- On-page recording indicator with session time, live step count, Pause/Resume and Stop & review.
- Chrome toolbar REC/paused badges and a shortcut back to the recording tab.
- Named QA sessions, human-readable actions, per-step results and expected/actual notes.
- Downloadable Markdown QA reports alongside the full JSON evidence export.

- Single-tab recording of clicks, committed form changes and navigation.
- Best-effort screenshots with viewport and pointer context.
- Unique primary CSS selector plus labeled alternatives.
- Local recording history; export/import JSON as independent copies.
- Selector edits saved to the selected completed run.
- Visual slideshow with pause/resume and manual step selection.
- Confirmed deletion of completed recordings.
- Readable popup errors and empty states; keyboard-accessible viewer lists.

Playback displays saved steps; it does not execute browser actions. See [README.md](README.md) for installation, permissions and supported limits, [REVIEW.md](REVIEW.md) for the readiness review, and [TEST_CASES.md](TEST_CASES.md) for manual acceptance checks.
